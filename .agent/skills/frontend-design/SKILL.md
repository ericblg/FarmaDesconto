# Frontend Design Principles

## 1. Aesthetics
- **Modern UI**: Use clean lines, generous whitespace, and balanced proportions.
- **Color Palettes**: Avoid generic colors. Use harmonious, curated palettes (e.g., tailored HSL colors, sleek dark modes). No purple or violet unless specifically requested by brand guidelines (Purple Ban).
- **Typography**: Use modern web fonts (e.g., Inter, Roboto, Outfit) instead of browser defaults. Ensure good readability and hierarchy.

## 2. Dynamic Interfaces
- **Interactivity**: Add subtle hover effects and micro-animations to buttons, cards, and interactive elements.
- **Responsiveness**: Ensure the design looks premium and functional on all device sizes (mobile, tablet, desktop).

## 3. Best Practices
- **Consistency**: Maintain a consistent design system (buttons, inputs, spacing) throughout the application.
- **Accessibility**: Ensure sufficient color contrast and accessible interactive elements for all users.
